# Jev 浏览器实验阶段汇总

实验使用独立本地合成知识目录页面和隔离浏览器，不涉及用户浏览器数据。A任务从相似记录中打开指定记录；B任务还需编辑两个字段、确认、保存并关闭编辑器。所有结果通过独立服务端 oracle 核验，不以模型自称完成作为唯一依据。

J1 用紧凑表示替换重复状态，保留全部候选，不提高48KB限制。真实 A180 运行的两次请求包含全部180候选，分别46268/46434字节，并成功打开正确记录。J0此前在A180因资源限制拒绝，未调用模型。该结果支持此次表示优化扩大可处理页面容量，但不能证明普遍准确率或速度提升。

E1仅增加进程内DNS地址排序，保留原HTTPS主机名及TLS验证。E0曾出现连接阶段超时；有限E1成功不构成DNS根因或稳定修复证明。原B8错误发生在HTTP200后的答案校验阶段，具体无效答案未留存，不能推断具体格式原因。本次失败没有模型错选证据：前七个动作正确，页面oracle成功；失败点在完成判定的答案校验，页面成功不能替代runner全流程成功。

跨版本复用依据是后续8b2a9cc仅追加安全诊断，未更改表示或动作策略；这并不意味着所有用例在同一版本/环境重跑过。所有历史失败与单步诊断均保留，诊断的oracle通过不计完整成功。

截至最终授权窗口，共21次Jev runner启动：14次done、6次error、1次单步诊断step_limit；另有master一次原payload纯API诊断，不计浏览器闭环。累计66次API占号/尝试，348943已知输入tokens、5次usage未知。新窗口五项全部通过，新增28请求/134516输入tokens/0未知。原BAD_ANSWER原因仍unknown，诊断未复现不能回填历史。

所有五项新运行以expected_text程序断言结束，最终模型goal_met分别0.60、0.80、0.59、0.76、0.63，均低于0.90。准确口径为Jev选择动作＋宿主文本完成断言＋独立oracle共同通过，不应称模型自主识别完成。expectedText不进入模型state，答案校验发生在程序完成断言之前。

授权矩阵现已通过（明确跨版本复用此前A8/A64/A120/round1A180），并非所有用例都在新SHA重跑。holdout只改变同一合成领域的干扰记录/位置，不代表新领域泛化；未证明普遍速度或准确率提升。下表保留最终五项运行结果；历史失败保持原记录。

## 环境与复现边界

实验在 Linux 上运行真实 Chromium 149、MV3 扩展和 MCP，独立临时 profile，扩展连接 17429，合成测试站监听 127.0.0.1:17430。浏览器操作不是模拟返回；机械离线测试与真实 Jev 调用分别记账。Jev 返回模型为 jev-1.13.0。

E1 是本次运行的临时环境调整：仅在测试 MCP 进程中重排 api.typesafe.ai 的正常 DNS 返回地址，保留全部地址、原域名、TLS 验证与超时；不修改系统 hosts，不自动重发 POST。preload SHA-256 为 `4aad102ff87c52af62a314cc6efe1cf144218dd3c0ac091c8278da3ee4e27af1`。它不是本项目默认行为，也不建议将当时的 IP 固定用于其他环境。历史连接超时原因未被充分定位，E1 的有限成功不能视为网络问题已永久修复。

这是小规模合成实验，页面提供规范可访问标签，模态框背景控件显式禁用；不能代表无标签控件、任意真实网站、视觉任务或新领域泛化。

运行入口和参数见[实验指南](../jev-lab.zh-CN.md)。实验需要真实 TypeSafe API key，普通离线测试不会调用模型；密钥应来自宿主环境，不应写进仓库。
